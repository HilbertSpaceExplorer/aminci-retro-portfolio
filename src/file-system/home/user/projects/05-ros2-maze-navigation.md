# Navigation

## 2024

### ROS 2 / Gazebo / Autonomous Navigation
### Python / LaserScan / Mobile Robotics

![](/images/terminal/projects/ros2-maze-navigation/gazebo-maze-overview.png?aspect=1.78&width=1.2)

A university project focused on programming a simulated mobile robot for unknown corridors and mazes.

The work progressed from path-planning logic and precise motion sequences to laser-based wall alignment, collision avoidance, dead-end handling, and autonomous maze navigation.

The Python controller used ROS 2 topics to receive 360-degree laser scans and publish velocity commands. The algorithms were tested in Gazebo on several supplied layouts and assessed on an additional unseen environment.

The project developed practical experience with ROS 2 nodes, publishers and subscribers, sensor interpretation, reactive control logic, simulation-based debugging, and mobile robotics.
