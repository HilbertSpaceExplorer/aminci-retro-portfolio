# Vision-Based Robot Laptimer

## 2025

### Computer Vision / ArUco Tracking
### Python / OpenCV / Mobile Robotics

![](/images/projects/laptime-stopwatch/cover.jpg?aspect=1.157&width=1.2)

A camera-based timing system for small autonomous robots.

The system detects robot markers, tracks lap events, filters noisy measurements, and produces timing data for evaluating line-following performance.

It combines real-time vision, marker detection, signal smoothing, and experimental performance analysis.
