# Vision-Based Robot Laptimer

## 2025

### Computer Vision / ArUco Tracking
### Python / OpenCV / Mobile Robotics

![](/images/projects/laptime-stopwatch/experiment-screenshot.png?aspect=1.778&width=1.2)

A camera-based timing system for small autonomous robots.

The system detects two ArUco markers, estimates their 3D separation, smooths the distance signal, and calculates lap intervals from successive local minima.

The implementation uses real-time vision, pose estimation, signal processing, live plotting, and saved measurements for later comparison.
