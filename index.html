LAB FILE 01 PUBLIC SUMMARY

ROBOTICS / SENSING / MODEL VALIDATION

Continuum Robot Shape Prediction

A public overview of an experimental workflow for predicting continuum robot shape under external forces using physical sensing, stereo vision, and model-based validation.

  • MATLAB / Simulink
  • Python
  • Stereo Vision
  • Force Sensing

CONFIDENTIALITY NOTE — Specific geometry, datasets, institute equipment, and results are intentionally omitted.

01 / Problem

External contact forces deform continuum robots, making shape prediction from actuation information alone difficult.

02 / My contribution

I developed an experimental workflow connecting force measurements, vision-based shape observations, and model validation.

03 / Technical approach

Synchronized sensing and stereo observations are transformed into comparable measurements for evaluating predicted and observed robot shapes.

04 / Current outcome

The work establishes a repeatable validation pipeline while keeping confidential experimental details outside the public portfolio.

What this demonstrates

  • Experimental design
  • Sensor integration
  • 3D computer vision
  • Physical-system validation
  • Scientific computing
LAB FILE 02 VISION SYSTEM · 2025

ROBOTICS / COMPUTER VISION

Vision-Based Robot Laptimer

A camera-based stopwatch that detects robot crossing events and records lap times for more repeatable performance testing.

  • Python
  • OpenCV
  • ArUco Tracking
  • Video Processing

01 / Problem

Manual stopwatch measurements introduce reaction-time errors and make robot configurations harder to compare objectively.

02 / My contribution

I built a vision-based timing workflow that detects a robot at a defined start and finish region and records crossing events.

03 / Technical approach

OpenCV processes the video stream, tracks the relevant marker, filters repeated detections, and converts valid events into lap measurements.

04 / Result

The system provides a more consistent timing method for comparing control settings, robot configurations, and test runs.

What this demonstrates

  • Practical computer vision
  • Automated measurement
  • Robotics testing
  • Noise filtering
  • Performance evaluation
LAB FILE 03 CONTROL TEST · 2025

CONTROL / VISION / DATA ANALYSIS

PID Robustness Evaluation

A quantitative workflow for evaluating distance-control behaviour using computer-vision measurements from repeatable robot experiments.

  • PID Control
  • Python
  • OpenCV
  • Data Analysis

01 / Problem

A controller that performs well under ideal conditions can still become inaccurate or unstable when disturbances and initial conditions change.

02 / My contribution

I developed a vision-based evaluation workflow for measuring how robustly a mobile robot maintains a target distance.

03 / Technical approach

Video-derived measurements support analysis of distance error, overshoot, oscillation, settling behaviour, and sensitivity to disturbances.

04 / Result

The workflow creates a more objective basis for comparing PID behaviour across controlled test conditions.

What this demonstrates

  • Control engineering
  • Vision-based measurement
  • Quantitative evaluation
  • Robustness analysis
  • Experimental validation
LAB FILE 04 ML ANALYSIS · 2025

MACHINE LEARNING / INDUSTRIAL DATA

Compressed-Air System ML

A machine-learning workflow for classifying operating states and estimating flow behaviour from compressed-air sensor data.

  • Python
  • Classification
  • Regression
  • Sensor Data

01 / Problem

Operating states such as normal use, leakage, idle behaviour, and active consumption are not always obvious from raw sensor signals alone.

02 / My contribution

I developed a data-analysis workflow for identifying system states and estimating flow-related behaviour from measurements.

03 / Technical approach

Pressure, flow, power, and related sensor variables are prepared for classification and regression models and evaluated as engineering signals.

04 / Result

The project shows how industrial sensor data can support state recognition, condition monitoring, and performance analysis.

What this demonstrates

  • Machine learning
  • Industrial data analysis
  • Sensor-based monitoring
  • Classification and regression
  • Engineering interpretation
