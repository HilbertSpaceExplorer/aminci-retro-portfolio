# Continuum Robot Shape Prediction

## 2026 / In Progress

### Robotics / Stereo Vision / Force Sensing
### MATLAB / Simulink / Python

![](/images/projects/continuum-robot/cover.png?aspect=0.807&width=1.2)

Predicting how a flexible tendon-driven robot bends under external force.

I am building an experimental pipeline that combines force sensing, stereo vision, marker tracking, and model-based validation. The goal is to compare predicted robot shapes with measured 3D backbone data.

The work connects robotics, sensing, control, synchronization, parameter identification, and experimental validation.
