# Compressed-Air System ML

## 2025

### Machine Learning / Sensor Data
### Classification / Regression / Python

![](/images/projects/compressed-air-ml/cover.jpg?aspect=1.667&width=1.2)

Using machine learning to understand the state of a compressed-air system.

This project applies data-driven methods to classify system behaviour and estimate flow conditions from pressure, volume-flow, and power measurements.

The workflow covers preprocessing, feature analysis, model training, regression, classification, and evaluation.
